This is the [Prettier](https://prettier.io/) configuration used by
[John Karahalis](https://www.johnkarahalis.com) in his personal projects.

## Installation

Run `npm install @openjck/prettier-config`.

## Usage

1. Add `"type": "module"` to _package.json_.
2. Create a _.prettierrc.js_ file with the following contents:

```javascript
import openjckPrettierConfig from "@openjck/prettier-config";

export default openjckPrettierConfig;
```
